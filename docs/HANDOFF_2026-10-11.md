# DentiSys handoff — 2026-10-11

Branch: `lighthal8`. Task: `t5`, scheduled attendance session update API.

Implemented the Owner-approved edit rule in [spec.md ATT-001](../spec.md), preserving ATT-003. Backend and API client only; the UI remains future work. No specification amendment or database migration is needed.

Both `POST /api/faculty/attendance/session/update` and `POST /api/secretary/attendance/session/update` require `sessionId`. Their timing and location fields match each role's creation parser: `sessionDate` (or `date`, defaulting to today in Asia/Manila), `openingTime`, `presentCutoff`, `lateCutoff`, required `classEndTime`, `room`, `biometricRequired`, `geofenceEnabled`, `geofenceLatitude`, `geofenceLongitude`, and `geofenceRadiusMeters`. Secretary also retains `requireFace` and `requireGeo` aliases. This is a replacement of those settings using creation defaults; callers should send their complete intended settings. Class selectors are ignored and the existing class and session code are preserved.

Success is HTTP 200 with `{ "status": "ok", "session": <attendance_session_map(row, true)> }`. A new opening that is already due produces `active`; otherwise it produces `scheduled`, using the creation status helper. The shared update locks the class before the session, checks scheduled status and authority under those locks, excludes itself from overlap checks, verifies one updated row, and commits the `attendance_session_updated` audit with actor, timestamp and previous/new settings. Audit decimals are strings, as required by the existing audit writer; API location values remain numeric. The audit action code is unrestricted by the schema and audit writer. No attendance record is created, deleted or changed by the edit.

Faculty can edit any scheduled session in an assigned active, current class. Secretary can edit only their own scheduled sessions in an assigned active, current class. Secretary creation stores its acting user in `secretary_user_id` and `owner_user_id` and sets `created_by_role = 'secretary'`; Faculty creation sets `created_by_role = 'faculty'`. These creator columns are not rewritten by edits. All three values must match for Secretary edits, so missing or ambiguous ownership is denied without backfilling historical data.

Errors:

- 400 `BAD_REQUEST`: missing body or invalid `sessionId` (a positive integer within the database integer range).
- 404 `NOT_FOUND`: missing or unmanageable session; other classes' sessions are not disclosed.
- 403 `ATTENDANCE_SESSION_EDIT_FORBIDDEN`: "You can edit only sessions you created."
- 409 `ATTENDANCE_SESSION_NOT_EDITABLE`: "Only scheduled sessions can be edited."
- 409 `CONFLICT`: unchanged creation overlap message; past school-year classes remain view-only and the existing active-session uniqueness guard remains enforced.
- 422 `VALIDATION_ERROR`: unchanged creation validators and field messages.
