# Roadmap

What's next, in order. Each item is one feature: agree the contract, implement, run the gates, then start the next. Details and status are in the [product backlog](PRODUCT_BACKLOG.md); behaviour is defined by [spec.md](../spec.md); what already works is in [features.md](features.md).

1. **Small fixes** — class counts, bundle size and the Full Matrix View export (backlog 9.1, 9.3, 9.9; each waits on an Owner decision).
2. **UI items, one demo at a time** — the Faculty invitation View action, Grade Computation confirmations, remedial record details, large attendance lists, Email Management filtering, the phone-width pass, session card states, and the wording decisions (backlog 4.3, 5.2, 5.4, 5.6, 5.7, 10.7, 10.8, 9.7, 10.6).
3. **Superadmin mode** — the Dean's Superadmin toggle for grade and attendance changes, the course catalog and account deactivation (backlog 4.5–4.7); needs a spec section and a contract first.

The BU-format grade sheet export (backlog 9.4) waits until the Owner scopes it.
