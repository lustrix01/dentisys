### 9.31 Grade Computation: sidebar link stays on `/grades` after switching class

- **Files changed:**
  - `frontend/src/pages/faculty/GradeComputation.tsx`
  - `e2e/grade-computation-leave.spec.ts` (new)
- **Root cause (app bug):**
  - In `frontend/src/pages/faculty/GradeComputation.tsx:2204-2252` (`loadGradingConfig`), when switching to a course whose saved period config mismatches its `courseStructure` (`lecture_laboratory` -> `lecture`, `combined` -> `lecture`, or `lecture` -> `lecture_laboratory`), the loader auto-opened a structure-adjusted draft (`setComponentMode(draftMode)`, `setMidtermCategories(mDraft)`, `setFinalCategories(fDraft)`, plus `setTermRatio` and `setComponentWeights`) while leaving `savedComponentMode`, `savedMidtermCategories`, `savedFinalCategories`, `savedTermRatio`, and `savedComponentWeights` at the old loaded values.

  - `handleSelectOffering` (`GradeComputation.tsx:2366-2401`) also did not reset `termRatio`/`savedTermRatio` when clearing offering state during a class switch.
- **Behaviour change:**
  - Synced `savedComponentMode`, `savedMidtermCategories`, `savedFinalCategories`, `savedTermRatio`, and `savedComponentWeights` to the auto-opened structure draft in `loadGradingConfig` (matching the existing unconfigured preset draft pattern at lines 2012-2063). The `Save grade weights` button is not gated by `isDirty`, so Faculty can still save the structure-adjusted draft directly, and the `!isDirty` status line (`BU Dental Medicine Lecture-only draft`) is now reachable as written.
  - Reset `termRatio` and `savedTermRatio` to `{ midterm: '50', final: '50' }` in `handleSelectOffering`.
  - No visible design changes (`Demo: none - logic-only fix with nothing visible`).
