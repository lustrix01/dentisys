### 9.31 Grade Computation: a sidebar link stays on `/grades` after switching class

Found by the Owner in the real app on 2026-11-24 (it was there before 14.10).

Steps: sign in as Faculty, open Grade Computation, switch to another class with the class picker, change nothing, then click any sidebar link (e.g. Dashboard). Wrong: the page stays on `/grades`. Leaving the page then (closing the tab or reloading) shows the browser's "leave page?" prompt although nothing was edited. Right: the link goes to its page, with no prompt, because nothing is unsaved.

Line hints in `GradeComputation.tsx`:
- around line 1333: the `beforeunload` guard, which fires when `weightsDirtyRef`, `singleDirtyRef`, `matrixDirtyRef` or a debounce timer is set;
- around line 2330: `unsavedWorkRef.current = isDirty || hasUnsavedSingleScores()` and the capturing click handler that stops in-app links when `unsavedWorkRef` is true;
- around line 2353: `handleSelectOffering`, which clears the loaded config while switching. A likely cause is `isDirty` (or a dirty ref / debounce timer) staying true after the switch because the saved and current weights are compared before the new class's weights have loaded. Confirm the real cause with the failing test; do not fix a guess.

Test contract:
1. After a class switch with no edits, a sidebar link click lands on the link's page, and no confirmation dialog appears. Fails before the fix.
2. After a class switch with no edits, `beforeunload` is not cancelled (in Playwright: register a `page.on('dialog')` handler and check no `beforeunload` dialog appears on `page.close({ runBeforeUnload: true })`). Fails before the fix.
3. Still true after the fix (already covered by Grade Computation tests; keep them passing): with an unsaved grade-weight edit, a sidebar link click asks "Discard unsaved changes?", and Cancel stays on `/grades`.

Use the mocked `e2e/` suite first (the bug is in the browser code). If it does not reproduce there, use `e2e/live/` with the real backend. If neither reproduces it, stop and report the exact steps tried.
