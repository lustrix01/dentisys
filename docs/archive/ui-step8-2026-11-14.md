## Lessons

- Before shots must come from unchanged code; dialogs that only appear on save cannot get an honest "before" without changing data.
- PHP `?? 'missing'` treats a real null as missing: use `array_key_exists` in tests.
- Backlog edits by script dropped a section once: check headings after every edit.
- A new label can split at 320 px: check the smallest phone before showing a wording change.
