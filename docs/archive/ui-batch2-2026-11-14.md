- **Dean:** a Dean / Superadmin switch. Superadmin shows the Audit Trail with a read-only Class work tab, a real Course Catalog (edit, retire, restore; migration 060) and People & Accounts (deactivate and reactivate Faculty and Students; refused for Faculty with current classes). Spec ADM-001.

## Lessons

- A superadmin edit path must reuse the existing guards of the Faculty path (GRD-003 Laboratory units).
- Live testing on the dev database changes seed data; restore it and record what changed.
- New pages copy tab bars by job: two views of one list use the grey list switch, not the section bar.
- PHP `?? x` turns a real null into the default again; use `array_key_exists` in tests.
