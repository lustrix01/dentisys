# Casing rule, November 2026: changelog

The Owner asked for one casing rule that later passes can follow without coming back to them. The rule is recorded in `spec.md` (UI-001, "Owner decision (2026-11-06): Interface casing") and applied across the frontend. The same batch closes backlog 9.6 and two alignment fixes the Owner asked for during review. Branch `lighthal9-responsive`; committed locally, not pushed.

## What the user sees now

- **Names are Title Case.** Page titles, card and section headings, dialog titles, tabs, sidebar items, table column headers, form labels, and stat and detail labels. Examples: "First Name *", "Institutional Email *", "University Email", "Reset Password", "Current Classes".
- **Everything else is sentence case.** Buttons, links, chips, status values, filter options, hints, tooltips, messages, and headings that read as messages. Examples: "View attendance", "Save result", "All school years", "No assigned classes found".
- **Always capitalised:** roles, DentiSys and BU, Midterm, Finals, Lecture and Laboratory, ID, PDF and CSV, and the semester names. A page, tab or button name inside a sentence keeps its own casing ("Open in Retention Monitoring").
- **No ALL CAPS in the code.** Table headers that show in capitals (Attendance) still do, through their style. The printed class list header stays in capitals, because it copies the official form.
- **Academic Terms:** an undated semester ("2nd Semester", "Summer") uses the standard readable grey instead of a 2.6:1 pale grey.
- **Archived Classes:** every archived card has the same rows: the course tag with Edit, then the status and block, then the title. Nothing pokes out of the card, and titles line up across a row of cards.
- **Faculty dashboard, Class Details:** the number badges keep their size, so the course codes line up from row to row.

About 540 text changes in 67 frontend files. Words were not changed, only their case.

## Owner rulings

- The casing rule above, approved 2026-11-06. The demo's R3–R5 additions were approved with the batch: semester names are always capitalised; page, tab and button names keep their casing inside sentences; stat and detail labels are Title Case.
- The printed class list header stays in ALL CAPS.
- Table headers styled in small capitals are left as they are. Six of the 41 tables use that style; the difference is noted in backlog 9.7.

## Lessons

- **Placeholders and tab names:** a bulk casing pass must treat placeholders as sentence case but a tab's accessible name as Title Case. The live tests caught the "Lecture Categories" tab and the "Category name" placeholder.
- **Page names in messages:** page names inside messages were lowered at first ("Open in retention monitoring"). The rule now says names keep their casing.
- **Styled capitals:** a heading styled in capitals shows no visible change. Pick a demo spot that shows the text as typed.
- **Check-in style:** both halves of a hyphenated word are capitalised in Title Case ("Check-In Time"). In sentence case it is "check-in".
